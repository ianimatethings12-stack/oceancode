title: "Plugins"
---

Add published packages, versioned packages, scoped packages, or local plugin directories to `oceancode.json(c)`.

## Configure

```jsonc title="oceancode.jsonc"
{
  "$schema": "https://raw.githubusercontent.com/ianimatethings12-stack/oceancode/dev/config.schema.json",
  "plugins": [
    "oceancode-acme-plugin",
    "oceancode-acme-plugin@1.2.0",
    "@acme/oceancode-plugin",
    "./plugins/local",
    "../shared/plugin.ts",
    "/absolute/path/plugin.ts",
    "file:///home/me/plugins/local",
    {
      "package": "@acme/oceancode-plugin",
      "options": {
        "agent": "reviewer",
        "strict": true,
      },
    },
  ],
}
```

Relative paths resolve from the config file containing the entry. Plugin arrays from applicable config files are applied
from lowest to highest precedence instead of replacing one another.

```text
~/.config/oceancode/oceancode.jsonc
./oceancode.jsonc
./.oceancode/oceancode.jsonc
```

## Discover

OceanCode also loads direct `.ts` and `.js` files and immediate plugin package directories from every discovered
`.oceancode/plugins/` directory.

```text
.oceancode/
└── plugins/
    ├── concise.ts
    ├── reviewer.js
    └── acme-package/
```

Global plugins use the same discovery layout under the OceanCode config directory.

```text
~/.config/oceancode/plugins/
```

A `plugins/` directory beside a project-root `oceancode.json(c)` is not discovered automatically; configure its files
explicitly or move it under `.oceancode/`.

```jsonc title="oceancode.jsonc"
{
  "plugins": ["./plugins/local"]
}
```

## Control

Plugin entries are processed in order. Prefix an ID or wildcard with `-` to disable it, use `*` for every plugin, and
use `.*` to match an ID prefix. A later ID re-enables a plugin.

```jsonc title="oceancode.jsonc"
{
  "plugins": ["*", "-oceancode.provider.*", "oceancode.provider.openai", "-acme.reviewer"]
}
```

Two built-in plugins ignore removals so that a repository cannot switch off
[policy](/policies) enforcement: `oceancode.config.policy` and
`oceancode.provider.oceancode`, the Console connection that delivers organization
policy.

## Manage

Install, list, check, update, or remove global package plugins with the CLI.

```sh
oceancode plugin add oceancode-acme-plugin@1.2.0
oceancode plugin list
oceancode plugin list --builtin
oceancode plugin check
oceancode plugin update
oceancode plugin update oceancode-acme-plugin
oceancode plugin remove oceancode-acme-plugin@1.2.0
```

`plugin check` checks server and TUI-only package plugins for updates. `plugin update` updates every outdated package;
pass a configured package target to check or update only that package. Local plugins and exact package revisions are skipped.

Package installation accepts npm names with versions, tags, or ranges, plus npm-compatible Git package specifications.
Git repositories can use hosted shortcuts, HTTPS, or SSH, including private repositories available through your existing
Git credentials.

```sh
oceancode plugin add @acme/oceancode-plugin@latest
oceancode plugin add github:acme/oceancode-plugin
oceancode plugin add git+ssh://git@github.com/acme/oceancode-plugin.git#main
oceancode plugin add 'github:acme/plugins#main::path:packages/oceancode-plugin'
```

Branches, tags, complete commit hashes, and npm's `::path:` repository-subdirectory selectors are supported. Configure
local paths directly; tarball and npm alias targets are not accepted by `plugin add`.

## Reload

Changes under watched config directories reload automatically. Server startup loads cached package plugins immediately,
installs missing packages in the background, and checks unpinned npm and Git plugins for updates without changing the
installed package. Exact npm versions and full Git commit hashes stay pinned. Changes to unwatched local dependencies may
still require restarting OceanCode.

```sh
touch .oceancode/plugins/concise/index.ts
oceancode service restart
```

## Terminal

CLI-only plugins are configured separately and remain active when connected to a remote server.

```json title="cli.json"
{
  "plugins": ["oceancode-acme-cli"]
}
```
