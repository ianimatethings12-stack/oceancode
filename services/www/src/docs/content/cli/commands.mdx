title: "Commands"
description: "Reference for the oceancode command line."
---

Every command accepts `--help` for its full flag list, for example `oceancode run --help`. Some server-backed commands accept `--standalone` to run a private server or `--server <url>` to target a specific one; check the command's help for its supported flags.

## run

Sends a message and prints the reply without opening the interactive interface.

```bash
$ oceancode run "Explain this repository"
```

### CI

In CI, pass a provider API key as a secret and use standalone mode so the private server receives it. For example, this GitHub Actions job reviews the checked-out repository:

```yaml
name: OceanCode review
on: [pull_request]

jobs:
  review:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: npm install --global @oceancode/cli
      - run: oceancode run --standalone --model anthropic/claude-sonnet-4-5 "Review this repository for correctness and summarize any issues."
        env:
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
```

Choose a model.

```bash
$ oceancode run --model anthropic/claude-sonnet-4-5 "Refactor parseToken"
```

Continue the last session.

```bash
$ oceancode run --continue "Now handle the expired case"
```

Emit newline-delimited JSON for scripts.

```bash
$ oceancode run --format json "List the TODO comments"
```

Attach files to the message.

```bash
$ oceancode run --file src/server.ts --file src/client.ts "Review these for bugs"
```

Run with a specific agent.

```bash
$ oceancode run --agent build "Fix the failing test"
```

View all subcommands and flags.

```bash
$ oceancode run --help
```

## mini

Starts the minimal interactive interface instead of the full-screen TUI.

```bash
$ oceancode mini
```

Continue the last session.

```bash
$ oceancode mini --continue
```

Start with a model and an initial prompt.

```bash
$ oceancode mini --model anthropic/claude-sonnet-4-5 --prompt "Summarize this repository"
```

View all subcommands and flags.

```bash
$ oceancode mini --help
```

## session

Manages sessions.

```bash
$ oceancode session list
```

Limit the list and print JSON.

```bash
$ oceancode session list --max-count 20 --format json
```

Delete a session and its child sessions.

```bash
$ oceancode session delete ses_9c1b08
```

Export session data as JSON.

```bash
$ oceancode session export ses_4f2a1c
```

Redact sensitive transcript and file data when exporting.

```bash
$ oceancode session export ses_4f2a1c --sanitize
```

Import session data from a JSON file or URL.

```bash
$ oceancode session import session.json
```

Import into a specific directory.

```bash
$ oceancode session import session.json --directory ~/code/project
```

View all subcommands and flags.

```bash
$ oceancode session --help
```

## auth

Manages AI providers and credentials.

```bash
$ oceancode auth list
```

List them as JSON.

```bash
$ oceancode auth list --format json
```

Log in to a provider.

```bash
$ oceancode auth login anthropic
```

Log in with a specific authentication method.

```bash
$ oceancode auth login anthropic --method key
```

Log out of a saved account.

```bash
$ oceancode auth logout anthropic work
```

Switch the active account for an integration.

```bash
$ oceancode auth switch anthropic work
```

View all subcommands and flags.

```bash
$ oceancode auth --help
```

## mcp

Manages MCP (Model Context Protocol) servers.

```bash
$ oceancode mcp list
```

Add a remote server.

```bash
$ oceancode mcp add context7 --url https://mcp.context7.com/mcp
```

Add a local server to the global config.

```bash
$ oceancode mcp add everything --global -- npx -y @modelcontextprotocol/server-everything
```

Add a local server with an environment variable.

```bash
$ oceancode mcp add everything --env LOG_LEVEL=debug -- npx -y @modelcontextprotocol/server-everything
```

Add a remote server with a header.

```bash
$ oceancode mcp add context7 --url https://mcp.context7.com/mcp --header CONTEXT7_API_KEY=secret
```

Authenticate with an OAuth-capable remote server.

```bash
$ oceancode mcp auth sentry
```

Remove stored OAuth credentials for a server.

```bash
$ oceancode mcp logout sentry
```

View all subcommands and flags.

```bash
$ oceancode mcp --help
```

## plugin

Manages plugins.

```bash
$ oceancode plugin list
```

Include built-in server plugins.

```bash
$ oceancode plugin list --builtin
```

Install a plugin and add it to the global configuration.

```bash
$ oceancode plugin add @example/oceancode-tui
```

Check package plugins for updates.

```bash
$ oceancode plugin check
```

Update package plugins.

```bash
$ oceancode plugin update
```

Remove a plugin from global configuration.

```bash
$ oceancode plugin remove @example/oceancode-tui
```

View all subcommands and flags.

```bash
$ oceancode plugin --help
```

## serve

Starts the API and web server. See [Web](/cli/web).

```bash
$ oceancode serve
```

Bind to all interfaces on a fixed port.

```bash
$ oceancode serve --hostname 0.0.0.0 --port 4096
```

Allow a browser client from another origin.

```bash
$ oceancode serve --cors https://app.example.com
```

View all subcommands and flags.

```bash
$ oceancode serve --help
```

## pair

Prints one-time links, plus a QR code of the first one, that sign a browser or
app in to the server. Links expire after 5 minutes and work once.

```bash
$ oceancode pair
```

Use an external URL in the links.

```bash
$ oceancode pair --url https://dev.example.com
```

Pair from anywhere through an OpenTunnel remote address. This exposes the
server to the internet, so the first time it enables remote access it explains
this and asks you to accept. See [Remote access](/cli/web#remote-access).

```bash
$ oceancode pair --remote
```

Accept without a prompt, for example in a script without a terminal.

```bash
$ oceancode pair --remote --yes
```

View all subcommands and flags.

```bash
$ oceancode pair --help
```

## service

Manages the background server. See [Web](/cli/web).

```bash
$ oceancode service start
```

Restart it.

```bash
$ oceancode service restart
```

Show its status.

```bash
$ oceancode service status
```

Stop it.

```bash
$ oceancode service stop
```

Read a setting.

```bash
$ oceancode service get hostname
```

Set a setting.

```bash
$ oceancode service set hostname 0.0.0.0
```

Allow an extra CORS origin.

```bash
$ oceancode service set cors https://app.example.com
```

Pass an environment variable to the server process.

```bash
$ oceancode service set env OCEANCODE_LOG_LEVEL DEBUG
```

Reset a setting to its default.

```bash
$ oceancode service unset hostname
```

View all subcommands and flags.

```bash
$ oceancode service --help
```

## reload

Reloads configuration without restarting the server. Running sessions continue with fresh services at the next step boundary.

```bash
$ oceancode reload
```

## api

Makes a request to the running server.

```bash
$ oceancode api GET /api/session
```

Call an operation ID with a query parameter.

```bash
$ oceancode api session.list --param limit=10
```

Send a JSON body.

```bash
$ oceancode api session.create --data '{"title": "New session"}'
```

Add a request header.

```bash
$ oceancode api GET /api/session -H "accept: application/json"
```

View all subcommands and flags.

```bash
$ oceancode api --help
```

## upgrade

Upgrades OceanCode to the latest or a specific version. Alias: `update`.

```bash
$ oceancode upgrade
```

Upgrade to a specific version with a specific package manager.

```bash
$ oceancode upgrade 2.0.21 --method bun
```

View all subcommands and flags.

```bash
$ oceancode upgrade --help
```

## uninstall

Stops background services, removes the global cache, and uninstalls OceanCode. Session data, configuration, and
state are not removed.

```bash
$ oceancode uninstall
```

Preview what would be removed.

```bash
$ oceancode uninstall --dry-run
```

View all subcommands and flags.

```bash
$ oceancode uninstall --help
```
